01 — about

Four+ years of turning designs into interfaces that hold up.

I'm Rashmi, a frontend engineer with 4+ years of experience building React applications at industry level — growing from an Associate Software Engineer role into a Frontend Lead position, currently leading UI development on a large-scale ERP system. I've shipped four production projects as part of engineering teams, plus a personal admin panel built end-to-end on my own — from architecture to deployment.

My focus is the part of frontend that's easy to get wrong: state that doesn't fight itself, components that don't leak assumptions, secure authentication flows, and performance that holds up once real data and real users show up.

I'm now opening up my time to freelance and contract work, and I care about the handoff as much as the build — clean PRs, clear docs, and code the next engineer (or future me) can actually read.
